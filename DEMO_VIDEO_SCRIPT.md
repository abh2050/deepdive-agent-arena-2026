# DeepDive — Judge-Ready 2-Minute Demo Script

**Runtime:** 1:56 target, 2:00 hard ceiling

**Format:** 1920×1080, 16:9, narrated screen recording

**Tone:** Polished forensic thriller — proof, not promises
**Live app:** https://deepdive-agent-arena-2026.vercel.app/

## The story in one line

Most AI research asks you to trust the answer. DeepDive makes every published
claim prove itself.

## Before recording

- Use a clean browser profile at 100% zoom and 1920×1080.
- Close bookmarks, notifications, developer tools, and every page containing a
  token or API key.
- Confirm the header reports `Mesh API: Active` and **Demo Mode is off**.
- Preload: `What evidence supports and limits the energy savings of residential heat pumps?`
- Record one complete real run. Condense only the wait and keep
  `Real Mesh run — wait condensed` visible over that cut.
- Capture the result before recording narration so every spoken run-specific
  number matches what judges see. Never reuse an old number with a new run.

## Edit and audio direction

- Use clean cuts for UI actions and one soft crossfade into the final hero.
- Keep the cursor deliberate; add a subtle ring only on clicks that matter.
- Use a restrained investigative music bed at roughly 12–15% under narration.
- Add only three quiet effects: query submit, verified-result reveal, final logo.
- Hold every inspector field long enough to read. Do not speed-ramp evidence.
- Use captions throughout; emphasize **verbatim**, **independent**, **rejected**,
  **inspectable**, and **auditable** with the app’s cyan accent.
